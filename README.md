# 📱 Android Studio Projects
В данном  мобильнии приложении, которое может авторизировать, загистрировать, имеет собствуную базу данных в которой храниться меню блюд, которые вы можете заказать, как пользователь. 

## 🎯 Основной функционал
1. Система аутентификации (Identity Management)
Регистрация и Вход: Реализована валидация email (Regex) и проверка сложности пароля.

Session Management: Сохранение состояния входа (пользователю не нужно авторизоваться при каждом запуске).

2. Каталог и Меню
Динамический список: Использование RecyclerView с кастомными адаптерами для плавного скроллинга.

Детализация: Индивидуальные карточки товаров с описанием, ценой и изображениями.

3. Корзина и оформление заказа
Логика подсчета итоговой стоимости в реальном времени.

Обработка транзакций при подтверждении заказа.

4. История заказов
Персонализированный архив покупок.

Сортировка заказов по дате (от новых к старым).

## 🏗 Как устроены данные (Data Layer)
Приложение использует реляционную структуру данных:

Users Table: ID, login, password_hash.
Products Table: ID, title, price, category, image_url.
Orders Table: Order_ID, User_ID, Timestamp, Total_Price, Items_List.
